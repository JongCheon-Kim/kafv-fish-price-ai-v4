# KAFV 수산물 가격정보 AI v4

- 앱 버전: **v0.17**
- Cloudflare Worker: **v0.6**
- 저장소 권장명: `kafv-fish-price-ai-v4`
- 핵심: **품목명 하나 → 가격정보 8개 Endpoint 자동 통합탐색 + 경매·온라인 별도 자동탐색**

## 설계 원칙

1. 품목코드는 자동탐색 중 바꾸지 않습니다.
2. 어기·비어기는 검색 차단조건이 아니라 해석정보입니다.
3. 단위·규격은 검색조건에서 제외하고 실제 API 응답값으로 표시합니다.
4. 정확조건 0건이면 Worker가 세부조건/날짜/공간 범위를 단계적으로 완화합니다.
5. 경매·온라인은 가격 API와 코드체계가 다르므로 동일코드로 합치지 않습니다.
6. 0건과 API 오류를 구분하고 가상·추정 데이터를 만들지 않습니다.

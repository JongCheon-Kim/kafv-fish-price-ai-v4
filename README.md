# KAFV 수산물 가격정보 AI

> 공공 수산물 가격데이터를 기반으로 품목·시장·지역·추세·거래 정보를 모바일에서 빠르게 조회할 수 있도록 구현한 PWA/TWA 기반 수산물 가격정보 서비스

## 1. 프로젝트 개요

**KAFV 수산물 가격정보 AI**는 한국AI어촌가치연구소(KAFV)가 개발한 수산물 가격정보 서비스입니다.  
공공데이터 API와 Cloudflare Worker를 연결하여 최근가격, 가격추세, 등락정보, 지역·시장별 가격, 경매·온라인 도매 등의 정보를 모바일 중심 UI에서 조회할 수 있도록 구성했습니다.

- 운영 형태: **PWA + Google Play TWA**
- 프런트엔드: **GitHub Pages**
- API Gateway: **Cloudflare Worker**
- 운영 Worker: **v0.7.2**
- 현재 UI 버전: **v0.27**
- Google Play 패키지: `kr.kafv.fishprice`

## 2. v0.27 주요 특징

### 모바일 중심 UI
- 3열 × 5행 홈 카드 구조
- 총 15개 카드: **14개 조회·정보 기능 + 사용방법**

4. 가격추세
5. 등락정보
6. 연월별 통계
7. 지역별 가격
8. 기간 중도매

## 3. v0.27 핵심 개선

### 전체 품목 → 가격엔진 연결
`전체 품목`에서 품목을 선택하면 단순 코드 확인으로 끝나지 않고, 선택한 품목코드를 통합 가격조회 엔진으로 넘겨 실제 가격정보를 조회합니다.

### 시장 정보 → 가격시장 코드 매핑
시장 목록에 사용되는 코드와 가격 API에서 사용하는 시장코드가 서로 다른 문제를 보완했습니다.

- 사용자가 시장명 선택
- 시장명·지역 기준으로 가격 API 시장코드 매핑
- 매핑된 실제 시장의 최근 가격자료 조회
- 다른 시장 자료로 임의 대체하지 않음
- 자료가 없으면 `0건`으로 표시

### 4주 추세·등락 그래프
최근 4주 가격 흐름을 전체화면 그래프로 확인할 수 있습니다.

- 현재가격
- 1주 전
- 2주 전
- 3주 전
- 4주 전
- 전일/1주/1개월/4주 전 대비 등락 정보

공공 API 응답값만 사용하며 임의 가격을 생성하지 않습니다.

## 4. 통합검색

메인 검색창은 단순 품목검색이 아니라 다음 범주를 통합 탐색합니다.

- 조회 기능
- 품목명
- 유통단계
- 품종/상태
- 등급
- 지역
- 시장
- 경매시장
- 경매법인
- 경매 상품분류

`전체 품목`, `시장 정보` 등 목록형 기능도 검색창에 마우스를 올리거나 클릭하면 전체 목록을 펼쳐 선택할 수 있도록 구성했습니다.


## 5. GitHub Pages 업데이트

일반 UI 업데이트 시 기본적으로 다음 파일만 교체합니다.

```text
index.html
sw.js
```

Worker, manifest, 아이콘, 기존 운영 이미지 자산은 변경 목적이 명확하지 않으면 유지합니다.


## 6. 테스트 체크리스트

배포 후 다음 항목을 실제 GitHub Pages와 모바일 TWA에서 확인합니다.

- 앱 버전 표기
- API 상태
- 통합검색
- 품목 통합조회
- 최근/일별가격
- 가격추세·등락
- 연월별 통계
- 지역별 가격
- 중도매·소매
- 실시간 경매
- 온라인 도매
- 전체 품목 → 실제 가격조회
- 시장 정보 → 가격시장 매핑 및 실제 가격조회
- 4주 추세·등락 그래프
- 전체화면 세부선택/결과
- 결과 초기화
- `가 / 가+ / 가++` 글자 확대
- 모바일 TWA 자동 반영

## 7. 데이터 원칙

- 실제 공공 API 응답값을 우선합니다.
- 데이터가 없으면 `0건` 또는 자료 없음으로 명확히 표시합니다.
- 다른 품목·시장·지역 데이터로 임의 대체하지 않습니다.
- 가격값을 임의로 생성하거나 보간하지 않습니다.
- 코드체계가 다른 경우 명칭·지역 등 검증 가능한 기준으로 매핑합니다.
